Isse pehle ek asli problem fix karni hai — file weights

Player ya video kuch bhi banao, ye theek nahi hua to mobile par sab kuch atkega. Maine tumhare assets measure kiye:

  • MES (project 14): 7 images, total 48.5 MB. Resolutions 10160×15000, 15000×10633, 12704×15000… A single 15000×10633 JPEG browser me decode hone par ~638 MB RAM leta hai. Modal me 4 aise images = ~2.5 GB → mobile tab crash ho sakta hai. Ye abhi live modal me hai.
  • ANANTA CARNATION (project 13): 4 images = 17.4 MB — saari images 15000×7406, matlab decode hone par ~444 MB RAM each. MES se chhota nahi hai, sirf mb me halka hai.
  • Poora assets/ = 81 MB / 88 JPGs (81,353,306 bytes). Baaki 12 projects ka weight iske muqable theek hai (0.03–0.6 MB per image).
  • Fix: web derivatives — max 2000 px long edge, JPEG quality 80. MES 48.5 MB → ~2 MB (≈96% cut). Originals alag folder me rahenge, loss kuch nahi hoga kyunki on-screen 2000 px kaafi hai. Ye ek baar ka kaam hai.
Isiliye mera order ye hai: (1) image weights fix karo → (2) autoplay 3.5 s / BBS 4.2 s → (3) modal ko player banao → (4) phir video ya 3D add karo. Ulta kiya to player phansi bhi lagega aur tumhe lagega "player kharab hai".
